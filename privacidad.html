Política de privacidad

Esta aplicación es de uso personal y privado. Se utiliza únicamente para listar metadatos de archivos (nombres, rutas y fechas) de Google Drive mediante la API de Google, con permisos de solo lectura.

No se descarga, almacena, procesa ni comparte el contenido de los archivos. No se recopilan datos de usuarios ni se ceden datos a terceros.
